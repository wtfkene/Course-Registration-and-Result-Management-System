# Course Registration and Result Management System (CRRMS)

The Course Registration and Result Management System (CRRMS) is a web-based application designed to manage student course registration and academic results.

## Project Overview
CRRMS allows students to register courses and view their results, while administrators (lecturers) can add courses and upload student results. The system helps improve accuracy and efficiency in academic record management.

## Features
- Student registration
- Course creation
- Course registration
- Result upload
- Result viewing

## Technologies Used
- Python
- Flask
- SQLite
- Git & GitHub

## How to Run
1. Install dependencies using `pip install -r requirements.txt`
2. Run the application with `python app.py`
3. Access the API endpoints using a browser or Postman
